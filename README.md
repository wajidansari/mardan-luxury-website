# Mardan Luxury Next.js Website

## Run locally
npm install
npm run dev

Open http://localhost:3000

## Deploy to Vercel
1. Create a GitHub repository.
2. Upload this project.
3. Import the repository into Vercel.
4. Framework preset: Next.js.
5. Build command: `next build`.
6. Deploy.

## Important
Replace the Unsplash image URLs with Mardan's own project photography before launch.
Replace the contact form action with a real Formspree/Resend/FormSubmit endpoint.
Add the remaining service detail routes as the next build step:
- /services/landscape-design
- /services/landscape-construction
- /services/garden-maintenance
- /services/irrigation
- /services/pools-water-features
- /services/green-walls
- /services/plants
- /process
- /areas-we-serve

The current package gives you the premium visual system and core routes; those detail pages can reuse the same components and CSS.
